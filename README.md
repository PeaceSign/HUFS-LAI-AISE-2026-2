# 인공지능소프트웨어공학 (2026-2)

한국외국어대학교 Language & AI 융합학부 · 전공 3학년 · 목 4·5·6교시

수강생 전원이 함께 쓰는 공개 저장소입니다. 과제를 제출하는 곳이 아니라, **한 학기 동안 같이 굴리는 프로젝트**가 사는 곳입니다. 발표 세 번(6주 · 10주 · 15주)이 전부 여기 남은 기록 위에서 이루어집니다.

## 무엇을 만드나

**1주차에 다 같이 정합니다.** 지금은 비어 있는 것이 맞습니다.

세 가지 후보가 있고, 더 나은 제안을 내도 됩니다.

- **A — LLM을 바닥부터.** 순수 Python 199줄짜리 GPT에서 출발해 데이터·학습·평가·추론까지 붙여 나간다
- **B — 코딩 에이전트를 직접.** 도구 호출 루프에서 시작해 권한·컨텍스트·서브에이전트까지 우리 손으로 만든다
- **C — 우리가 실제로 쓸 도구.** 강의·학사 정보를 다루는 MCP 서버처럼, 만들고 나면 매일 쓰게 될 것

## 디렉토리

| 경로 | 무엇 |
|---|---|
| `members/` | 자기소개. 본인 학번으로 `.md` 파일을 만든다 |
| `.github/workflows/` | PR 제목 검사, approval 요건, 리뷰 리마인더 |

프로젝트 코드가 들어갈 디렉토리는 1주차 결정 후에 만듭니다.

## 처음 왔다면

1. 이 저장소를 fork 한다
2. `members/<본인 학번>.md` 를 만든다 — 이름과 학번은 반드시, 나머지는 자유
3. 브랜치를 파고 PR 을 올린다 — 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)
4. 동료 한 명의 approval 을 받는다. 그 다음 교수가 확인한다

## AI 사용

권장합니다. 이 과목은 AI로 개발하는 법을 배우는 과목입니다.
